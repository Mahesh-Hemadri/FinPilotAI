# FinPilotAI

An AI-powered Personal Finance Manager for Android.

## Overview

FinPilotAI automatically reads transaction SMS messages, extracts financial information, categorizes expenses, tracks budgets, and provides AI-powered financial insights.

The app is designed to be privacy-first, storing data locally on the device while providing intelligent analytics and reporting.

---

## Features (Planned)

- Read bank transaction SMS
- Automatic debit/credit detection
- Merchant extraction
- Category prediction
- Budget management
- Monthly reports
- Charts & analytics
- AI-powered financial assistant
- Receipt scanner
- CSV / Excel export
- Cloud backup
